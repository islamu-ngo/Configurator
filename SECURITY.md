# Configurator Security

Do not disclose private answers, prepared restricted artifacts, credentials or
raw exception/path contents in public reports. Report a reproducible issue with
synthetic public input, the affected version and a value-safe failure code.
Coordinate sensitive disclosure privately with the Project Steward through a
verified repository maintainer channel; no reporting address is assumed here.

The utility prepares artifacts offline. Host acceptance remains the target
application's responsibility. Browser operation is public-only. Unsupported
protected native save must reject rather than fall back to ordinary file output.
Signed publication remains unavailable until Configurator establishes its own
trust authority.
