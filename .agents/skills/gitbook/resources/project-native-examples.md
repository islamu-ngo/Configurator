# Project-Native GitBook Examples

The site-derived Evolve Demo corpus is deliberately absent. It has no verified
transfer license and includes tokenized GitBook asset URLs. Do not fetch,
reconstruct or reuse that corpus. Create examples from Configurator's own
operator behavior and public contracts instead.

## Minimal operator documentation structure

Use a landing page, an offline workflow guide and a privacy/support page. Keep
native protected-save limits separate from browser public-input limits.

```markdown
# Configurator

Prepare configuration locally using a target definition. The target application
still validates and accepts the resulting artifact.

- [Offline preparation](offline-preparation.md)
- [Privacy and supported output](privacy-and-output.md)
```

```markdown
# Summary

* [Configurator](README.md)
* [Offline preparation](offline-preparation.md)
* [Privacy and supported output](privacy-and-output.md)
```

```yaml
root: ./
structure:
  readme: README.md
  summary: SUMMARY.md
```

Use repository-authored text, locally owned diagrams and approved component
notices. Do not invent a hosted origin, deployed catalog, live administration
capability or successful private save on an unsupported host. Preview actual
changed pages before publication and preserve the user's external-write
authorization boundary.
