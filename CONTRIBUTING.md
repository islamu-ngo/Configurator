# Contributing to Configurator

Read `AGENTS.md` and `PROJECTS.md` before editing. Use .NET SDK 10.0.302,
central package versions and Microsoft.Testing.Platform. Keep each change within
its owner and verify that owner; root tooling changes use engineering suites.

Definitions are bounded data, not executable plugins. No host authentication or
apply operation belongs in the offline engine. Keep private answers out of the
public browser and preserve create-only protected native output.

Contributions to ISLAMU-owned material follow MIT. Third-party code, assets and
dependencies retain their own terms; record provenance and required notices.
Do not import the excluded Evolve Demo corpus, Event trust or credentials.
Use `type(scope): description` commit subjects and the release scope registry.
Internal changes need `Changelog: skip` and a concrete `Changelog-Reason`;
breaking changes need both `!` and a `BREAKING CHANGE` explanation.
