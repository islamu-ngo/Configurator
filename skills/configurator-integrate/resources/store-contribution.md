# Prepare an optional store contribution

Review [secret policies](secrets.md) when the source declares secret fields.
Distribute public policy metadata only; never publish generated credentials or
an original password produced alongside a password hash.

First check/lint/build the authoring-0.0.1 source independently with the standalone CLI (command 0.0.1, authoring/runtime string 0.0.1), and verify complete/incomplete synthetic answers separately. The Store uses the same source and compiler; it cannot be a prerequisite for local CLI, native or browser use.

Place the same single handwritten source in the selected project directory. Include credential-free public repository information and an explicit license for the definition itself; the application's license is not an inferred redistribution license. Optional curator metadata supplies only tags or a meaningful slug exception. Do not recreate handwritten expanded project/runtime inventories. Distribute compiled canonical public runtime JSON, never private answer-0.0.1 workspaces, answer-derived artifacts or private defaults/examples. Public labels do not certify content or publisher trust.

Retain all canonical historical releases unchanged. Use native `init` for a new identity, `init --fork-from` for a new family, or `revise` against the existing canonical anchor followed by build for changed content in the same family. A family/revision cannot bind different canonical bytes. Store validation compares history against a separately supplied pinned target baseline; a contributor cannot select its own authority, remove admitted history or rebind a family to a different project.

Run the Store's native self-test and write/check commands in its documented lane. Review public text and literal suitability manually; schema admission is not curation or authentication. Return a review draft with source, generated release/digest and exact validation evidence, separating executed checks from remaining package/host/target qualification. Do not publish a PR or claim curation, signing or publication authority. Discovery and preparation grant neither target acceptance nor operator authorization or apply/restart permission.
